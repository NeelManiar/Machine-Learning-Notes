
**What is Machine Learning?**
Machine Learning is the field where we deal with patterns in data to make predictions, make classifications, and fundamentally break down data to its core to draw inferences in order to produce the best output possible.

Basic Parts are as follows:

1. ** Supervised Learning:** Applying machine learning concepts to labeled data to help with accurate predictions, regression, and building models in a perfectly organised manner.
   
2. ** Unsupervised Learning:** Applying machine learning concepts to unorganised, unlabeled, and messy data to help with clustering and improve the current data specs and structures.
